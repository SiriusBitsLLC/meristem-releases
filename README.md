# meristem-releases

Release files for Meristem. Its binary is `lane`.

Each release holds four archives (macOS and Linux, each for arm64 and x86_64), a sha256 file for each archive, the
shell installer, the Homebrew formula and `sha256.sum`.

Install with Homebrew:

```
brew install siriusbitsllc/tap/meristem
```

This repository holds release files only. Its one commit holds this file and `LICENSE`, and nothing else is ever
pushed to it.
